# TecAlliance Colour System

Source: TecAlliance Brand Guidelines 2026

Exact colour values are mandatory. Use the values below whenever the corresponding colour is referenced.

## Primary Colours

Primary colours represent the core TecAlliance identity and should be used predominantly across branding materials.

### Ignition Mango

- **Role:** Vibrant, energetic, dynamic accent colour.
- **Hex:** `#FF8700`
- **RGB:** `R255 G135 B0`
- **CMYK:** `C0 M47 Y100 K0`
- **Pantone:** `Pantone 2012 C`

### Circuit Slate

- **Role:** Strong, structured, modern colour for main assets.
- **Hex:** `#4B5568`
- **RGB:** `R74 G85 B104`
- **CMYK:** `C29 M18 Y0 K59`
- **Pantone:** `Pantone 432 C`

### Burnout Rubber

- **Role:** Deep, industrial, technology-driven colour for typography.
- **Hex:** `#2E2E2E`
- **RGB:** `R46 G46 B46`
- **CMYK:** `C0 M0 Y0 K95`
- **Pantone:** `Pantone Black 7 C`

### Pure White

- **Role:** Balance, clarity, clean design, and backgrounds.
- **Hex:** `#FFFFFF`
- **RGB:** `R255 G255 B255`
- **CMYK:** `C0 M0 Y0 K0`
- **Pantone:** `Pantone White`

## Colour Hierarchy

- **Pure White** `#FFFFFF`: approximately `60%` of the design (dominant base).
- **Burnout Rubber** `#2E2E2E` and/or **Circuit Slate** `#4B5568`: approximately `30%` (structure and readability).
- **Ignition Mango** `#FF8700`: approximately `10%` (accent, highlights, calls to action).

## Colour Usage Rules

1. Use **Pure White** `#FFFFFF` as the main background colour whenever possible.
2. Use **Burnout Rubber** `#2E2E2E` for primary typography.
3. Use **Circuit Slate** `#4B5568` for structured areas, supporting panels, dark interface elements, and secondary hierarchy.
4. Use **Ignition Mango** `#FF8700` sparingly for highlights, calls to action, accents, and emphasis.
5. Use product colours only when representing the relevant product identity:
   - TecDoc / Blueprint: `#0A74DA`
   - TecCom / Rapid Red: `#D22630`
   - TecRMI / Torque Teal: `#007A87`
6. Do not substitute approximate colours.
7. Do not invent additional brand colours unless explicitly requested and approved.
8. Ensure all foreground/background combinations meet accessibility contrast requirements.
